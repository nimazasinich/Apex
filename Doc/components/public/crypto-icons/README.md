# Local cryptocurrency icons

These local 32×32 PNG assets are pinned from the `spothq/cryptocurrency-icons`
v0.18.1 color set (CC0-1.0). They are bundled locally so the most common
markets render immediately without waiting for a third-party CDN.

Bundled symbols:
AAVE, ADA, ALGO, ATOM, AVAX, BCH, BNB, BSV, BTC, DASH, DOGE, DOT, EOS, ETC,
ETH, LINK, LTC, MATIC, SOL, TRX, UNI, XLM, XMR, XRP and XTZ.

Symbols not available in this bundle continue through the runtime fallback
chain and finally use the deterministic two-letter badge.
